# Fonts

Add the following font files to this directory:

1. **instrument-serif-regular.woff2** — Download from [Fonts.Adobe.com](https://fonts.adobe.com/fonts/instrument-serif) or [Google Fonts](https://fonts.google.com/specimen/Instrument+Serif)
2. **ibm-plex-mono-regular.woff2** — Download from [IBM Fonts](https://www.ibm.com/plex/) or [Google Fonts](https://fonts.google.com/specimen/IBM+Plex+Mono)

### Quick download (Google Fonts):

```bash
# Download Instrument Serif
wget -O instrument-serif-regular.woff2 "https://fonts.gstatic.com/s/instrumentserif/v6/jizAREdFvq-B7SLM3BfqQ3szzd.woff2"

# Download IBM Plex Mono
wget -O ibm-plex-mono-regular.woff2 "https://fonts.gstatic.com/s/ibmplexmono/v19/tss7APCTqv53R8vf7ljOFUUsLwkxFZp6UR17-Ej6-Zg.woff2"
```

Or manually download from Google Fonts:
- [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif)
- [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono)

Select "Regular 400" weight and download the WOFF2 files.
