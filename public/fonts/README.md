# Fonts

Add the following font files to this directory:

1. **eb-garamond-regular.woff2** — Download from [Google Fonts](https://fonts.google.com/specimen/EB+Garamond)
2. **ibm-plex-mono-regular.woff2** — Download from [Google Fonts](https://fonts.google.com/specimen/IBM+Plex+Mono)

### Quick download (PowerShell):

```powershell
.\download-fonts.ps1
```

### Manual download from Google Fonts:
- [EB Garamond](https://fonts.google.com/specimen/EB+Garamond)
- [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono)

Select "Regular 400" weight and download the WOFF2 files.
